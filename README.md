# web-python

Practice 1: in-memory data access layer for Entity, Query
and Feedback. Records are tuples. The REPL shows every
operation, including the 9-minute Query-Feedback join.

## Layout

- `src/` — application code
- `run.sh` — start the REPL
- `Makefile` — `make run`

## Requirements

- Python 3.10+
- [Scapy](https://scapy.net/) (`pip install scapy`)

## Run

```bash
./run.sh
```

or

```bash
make run
```

In the menu: `14` or `demo` runs all functions.
